   # RestaurantORM
   Лабораторна робота №8, варіант 10: облік замовлень ресторану (C++20, SQLite, sqlite_orm).

   ## Збірка та запуск
   1. Встановити Visual Studio з C++ та vcpkg.
   2. Відкрити папку проєкту (File > Open > Folder).
   3. Вибрати конфігурацію Windows x64, дочекатися встановлення залежностей через vcpkg.
   4. Запустити RestaurantORM.exe (Ctrl+F5).
